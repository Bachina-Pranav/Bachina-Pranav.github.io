## Highlights

- Designed a computer-vision system to classify and count cars, buses, and two-wheelers from image streams sampled every 10 seconds.
- Developed real-time data fetching and supported three YOLOv8 model sizes for different latency requirements.
- Built a dashboard to visualize traffic-management insights.
